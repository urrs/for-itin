A LITTLE LOVE QUEST — CHRISITIN

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder hasil ekstrak.
3. Klik dua kali index.html, atau jalankan melalui Live Server di VS Code.

Isi:
- index.html       Struktur halaman dan permainan
- style.css        Tampilan responsif, efek visual, animasi, dan dukungan safe-area iPhone
- script.js        Logika memory match (gambar dan pasangan selalu sinkron), timer, skor, efek partikel, bintang jatuh, efek pointer/tap, dan salin pesan
- assets/images/   4 ilustrasi SVG lokal (moon, flower, teddy, star)

Catatan:
- Tidak memakai framework atau library JavaScript eksternal.
- Font Google akan memakai font sistem jika koneksi internet tidak tersedia.
- Dirancang untuk Safari iPhone/iPad, Android, tablet, dan browser desktop.

Foto kenangan:
- assets/images/pic_Love.jpg — foto asli yang disertakan apa adanya, tanpa crop, filter, atau perubahan wajah.
